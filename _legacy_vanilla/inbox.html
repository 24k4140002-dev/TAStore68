Cài đặt CRM Inbox

Kết nối Supabase để lưu Labels, Tags và Ghi chú vĩnh viễn trên cloud. Chỉ cần làm 1 lần!

1
Tạo Supabase Project

Vào supabase.com → New Project → Chọn region Singapore

2
Chạy SQL Schema

Trong Supabase → SQL Editor → Paste toàn bộ nội dung file db-setup.sql → Run

3
Nhập thông tin kết nối

Settings → API → Copy Project URL và anon public key
